Approval batch 01 — Property rows

Five independent proposals grounded in the restored editor. Every Before image is a real current-editor capture. Every After image is a clean standalone rendering of the proposed final state, not an overlay. The user approved all five proposals on 8 September 2026.

Invariant for every proposal

All editing remains in the central property canvas. A displayed value becomes its editor in the same location when clicked, reached by Tab, or activated with Enter. Expanded facets remain directly below the property. The Inspector stays informational.

11

Proposal 11 — Compact inactive property rows

Reduce scanning height without hiding authored information or relocating editing.

Approved

Change

Inactive name, type, presence, and description values render as compact readable text in the existing grid.

Unchanged

Click, Tab, or Enter activates the same field in place. Disclosure, direct facets, keyboard flow, and the informational Inspector remain.

12

Proposal 12 — In-place field activation

Transform only the value being edited; preserve the row and surrounding context.

Approved

Change

The activated invoiceNumber text becomes the existing name input in the same cell. The linked After starts inactive so click, Tab focus, and Enter activation can be reviewed.

Dependency and invariant

This proposal depends on approval of item 11’s displayed-value state. The expanded inline facets and selected-property Inspector remain visible while the name is edited.

14

Proposal 14 — Collapsed authored summaries

Expose authored qualifiers and annotations without expanding the full detail editor.

Approved

Change

The collapsed distance row gains a restrained `unit m · symbol d` summary derived only from authored values.

Unchanged

Expanding the row still exposes the full inline annotation editors directly beneath distance.

18

Proposal 18 — Delete in row overflow

Remove the destructive action from the normal scanning path without hiding it remotely.

Approved

Change

Each row exposes one actions button. Its menu contains only the existing Delete property action; no new commands are proposed.

Unchanged

The current permanent field controls remain in this proposal so the delete-placement decision is isolated. Delete stays attached to the row and does not move to the Inspector.

19

Proposal 19 — Neutral row selection

Allow selection for context and navigation without treating selection as an edit command.

Approved

Change

The property row is a focusable grid row with `aria-selected`; neutral row activation selects invoiceNumber and updates the informational Inspector.

Unchanged

The current permanent controls remain in this isolated proposal. Clicking or tabbing to a specific control still activates that control rather than the row.
